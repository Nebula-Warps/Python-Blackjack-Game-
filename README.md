# Python Terminal Blackjack

A fully playable, text-based Blackjack game built entirely in Python. This project was developed to master core programming concepts, game loops, and state management.

## How to Play
1. Clone this repository to your local machine.
2. Open your terminal and navigate to the project folder.
3. Run the game using: `python blackjack.py`

## Tech Stack
*   **Language:** Python 3
*   **Concepts:** Object-Oriented Programming (OOP), loops, conditional logic, user input validation.

## Features
*   **Dealer Logic:** The dealer automatically draws cards based on standard Blackjack rules (drawing until 17).
*   **Dynamic Ace Handling:** The game intelligently handles Aces, converting them from 11 to 1 if the hand goes over 21.
*   **Input Validation:** The game uses error handling (`try/except`) to ensure the player can only enter valid inputs.
*   **Continuous Play:** The player can choose to keep playing multiple rounds without restarting the script.

## What I Learned
Building this 180+ line game was a major step in my coding journey. I learned how to structure a larger program, keep track of multiple states (the player's hand vs. the dealer's hand), and debug logical errors when the game didn't play out the way I expected.
